# Working agreement

- Plan before coding. For anything beyond a small fix, show the plan and wait for approval.
- Work in small steps that each leave the build and tests passing.
- Never say something works until you have run it. Show the real terminal output.
- If a test fails, fix the cause. Never weaken or delete a test to make it pass.
- Stay inside the current phase. If you see work that belongs to a later phase, note it in ARCHITECTURE.md ("Deferred work") and leave it.
- Keep changes minimal. No refactors or extra features that were not asked for.
- When unsure what is wanted, ask one clear question.
- When a feature ships or an install method becomes available, update the README in the same branch.
